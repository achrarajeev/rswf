# User flow (draft, to be completed)

Index: [Visitor](#visitor) | [Registered user](#registered-user) | [Institute](#institute)

## Visitor
Browse issues, open an issue, read overview, legal, emissions, people, evidence, sources, discussion.

## Registered user
Register, then open an issue and click Volunteer. Fill the form (how can you contribute). The name then appears under People. Pick an open task.

## Institute
Register with a registration number (checked). Join an issue. Maintain its open and taken tasks. Add evidence in the Evidence tab.
